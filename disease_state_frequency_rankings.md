# Disease State Frequency Ranking
Source file: `phase2_phase3_company_disease_states.md`

## Method
- Counted each disease state once per company if it appeared in either Phase 2/2b/2-3 or Phase 3/pivotal columns.
- Excluded rows with no current Phase 2/3 or pivotal treatment finding.
- Preserved specific indications rather than rolling everything up into broad therapeutic areas. Obvious wording variants were normalized, for example "NSCLC" and "non-small cell lung cancer."
- Ties are sorted alphabetically within the same count.
