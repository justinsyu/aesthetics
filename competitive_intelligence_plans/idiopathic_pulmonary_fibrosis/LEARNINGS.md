# Learnings

This file captures durable, disease-specific feedback and workflow lessons for future AI agents working in this folder.

- For IPF CI reports, avoid "evidence window" language outside the first-page date context, do not use "Factual scope" or "Source construction" viewer-facing sections, use formal source-attribution phrasing such as "states that" instead of "says", and title the final citation table "References" with source-agnostic column labels.
- Match card and panel chip spacing consistently; tag chips inside panels should have the same bottom spacing before headings as chips inside cards.
- IPF reports and plans should include only IPF-specific sources and facts; exclude adjacent pulmonary-fibrosis, pediatric, progressive-fibrosis, and broad interstitial-lung-disease data unless IPF-specific results are separately reported and cited.
