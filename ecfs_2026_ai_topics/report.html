Explicit AI/ML methods

AI/ML methods spanned registry and imaging studies

Explicit AI/ML methods

Registry lung-function models10

Machine-learning time-series models were used to estimate short-term FEV1 and FVC trajectories from CF Registry of Turkey data using CatBoost, nested cross-validation, hyperparameter optimization, and SHAP.

Trigger: machine learning; CatBoost; SHAP
Explicit AI/ML methods

AI-CT modulator assessment6

A retrospective pediatric CFTR modulator outcomes study states that chest CT scans were analyzed using AI-based methods, paired with Swedish registry lung-function data and mixed-effects modeling.

Trigger: Chest CT scans were analysed using AI-based methods
Explicit AI/ML methods

Registry clustering, CF states3

CFFPR encounter data were clustered using unsupervised machine learning and k-means to classify clinical states and transitions associated with lung transplant-free survival.

Trigger: unsupervised machine learning; k-means clustering
Explicit AI/ML methods

Organoid morphology workflow4

An AI-based morphology pipeline analyzed patient-derived intestinal organoids to distinguish wild-type from CF organoids and detect ETI-associated recovery.

Trigger: AI-based morphological analysis pipeline; AI-derived analysis
Explicit AI/ML methods

AI-HRCT imaging workflow5

A deep learning model analyzed chest HRCT images from 48 CF patients aged 10 to 18 years across five pulmonary findings, reporting 97% average accuracy, sensitivity, specificity, and F1.

Trigger: Artificial intelligence-assisted; deep learning-based diagnostic model
