# Cohere-style CI feedback applicability

Applicable: yes.

The ECFS 2026 AI topics task reinforces `cohere-style-ci` guidance for competitive-intelligence work that turns source evidence into visible reports. Audience-facing outputs should stay neutral, scientific, and concise, while source artifacts preserve provenance, retained-record tables, QA status, and evidence trails.

- Already covered: one-word heading and display-copy widows are treated as fixed-page defects to resolve before PDF handoff.
- Already covered: taxonomy and dense table headers should use readable, one-row labels with padding and vertical alignment balanced against body cells.
- Already covered: viewer-facing CI language should be scientific, objective, neutral, non-promotional, and free of unsupported recommendations.
- ECFS-specific clarification: the skill has some local-archive guidance that can surface local dataset/path details in methods text, but ECFS PDF feedback indicates those mechanics should stay out of visible report pages for this style of deliverable.

Generalized feedback for future competitive-intelligence work:

- Use objective scientific language for conference, abstract, trial, and publication analysis: records, presentations, abstracts, reported, described, included, retained, classified, and excluded.
- Avoid promotional or casual framing in headings, summaries, and caveats; prefer neutral labels such as "classification note" and "records reporting explicit methods."
- Keep local-file paths, source-log names, source-corpus details, CSV/JSON filenames, and run mechanics out of visible slides and report pages.
- Preserve provenance in source artifacts instead, including source logs, retained-record tables, QA notes, run manifests, and exclusion rationale when auditability is required.
- Use robust typography: avoid one-word heading, card, or table-label lines when they create awkward breaks; write compact multiword labels that fit the layout.
- For taxonomy tables, keep count columns compact, allocate more width to source and scope notes, and balance header-row top/bottom padding so labels do not look compressed or off-center.
- Use normal-weight taxonomy category labels unless hierarchy requires emphasis.
