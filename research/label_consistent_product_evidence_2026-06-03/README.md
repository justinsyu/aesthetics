# Label-Consistent Product Evidence Research Archive

Created: 2026-06-03

This folder contains research on best practices for communicating evidence for approved medical products in a way that is consistent with product labeling.

## Contents

- `consensus-summary.md`: short synthesis of the consensus and practical guardrails.
- `source-log.csv`: URL-by-URL inventory with local file mappings and notes.
- `documents/`: downloaded PDFs and other document-first sources.
- `webpages/`: saved HTML copies of source pages.

## Scope Note

The archive emphasizes U.S. FDA/OPDP, FTC, AMCP, ISPOR, PhRMA, and practical HEOR/vendor guidance. Medicines Australia was included as a recent practical non-U.S. promotional-claims reference because it gives concrete examples for RWE, NMAs, post hoc analyses, and comparative-claim substantiation.
