Key Building Blocks of GAIA

User Interface Layer

  • Role-based security that provides access to the appropriate documents
  • Supports in-browser rendering and downloads

Integration Layer

  • API Hub that supports secure integration with upstream and downstream systems

Document Orchestrator

  • Core Component configured for every document that defines the order of operations for how a document is generated
  • Supports full document, partial document, and package of documents generation

Feature Catalog

  • Common functions used to generate documents
  • Services include data extraction, data manipulation, document builder, table creation

Prompt Library

  • Centralized prompt library that stores prompts by document and section
  • Built for reuse as additional documents are added to the platform

LLM Router and Garden

  • Integration with AbbVie's LLM garden of cloud-hosted and privately-hosted LLMs
  • Centralized tracking of pricing and token usage

AWS Serverless Infrastructure

  • Built primarily with native AWS serverless infrastructure, to better support availability and auto-scaling

Agentic Catalog

  • Agent and MCP tools to simplify the design and development required to add documents to the GAIA platform

What We Have Learned On Our Journey

Organizational Change Management

AI solutions require new ways of working. Organizational change management plays a key role in readying the business to adopt GenAI, alleviating unspoken concerns related to job security.

Everyone Works In The New

Generative AI can be used to accelerate and optimize project delivery work. Agents and automation can eliminate manual work from PMO, SLC documentation, testing, and writing code or prompts.

Value Realization Strategy

Top-level stakeholders need clarity and alignment on baseline assumptions, relevant KPIs, and how results will be measured. This will help to ensure that decisions are made with an eye towards value creation and realization.

Business Participation in Development

Development teams must have access to medical writers that can provide feedback quickly and iteratively. Prompt-tuning is an art and a science, and it takes technical expertise and business participation.

Establish a team that's done this before

As with all new leading technologies, there is a learning curve for everyone. Stack the project with people who bring a mix of industry, data, AI/GenAI, and quality compliance to bridge learning gaps.

Define Accuracy, Writing Style, and Formatting Early

Generated outputs are never the same twice. It's important to align on the acceptance criteria for accuracy, writing style, and formatting to ensure the development team tests against the right expectations.
