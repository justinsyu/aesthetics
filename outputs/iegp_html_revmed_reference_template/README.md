# IEGP HTML Template

This folder contains a fixed 16:9 HTML slide deck template for integrated evidence generation planning.

Open `index.html` in a browser. Use arrow keys, Page Up/Page Down, Home, and End to navigate. Print to PDF with the browser print dialog if a PDF handoff is needed.

The visual system is adapted from the provided local reference deck. It uses reusable design principles only: teal clinical modules, small accent bars, hex page markers, geometric section dividers, compact evidence tables, and clean investor-style evidence hierarchy. It does not include copied logos, proprietary photos, or source slide assets.
