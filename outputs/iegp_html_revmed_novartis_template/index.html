Source basis

Template design is source-informed, but not a copy of any company’s slides

Revolution Medicines / AACR scientific slides
Used as design inspiration for scientific evidence density, green pathway accents, clinical tables, response/waterfall-style data framing, and direct study design pages.
Novartis investor slides
Used as design inspiration for large blue claims, left navigation, white space, light gray evidence panels, sparse orange decision markers, and image-style section breaks.
Adaptation guardrail
No logos, proprietary photography, copied charts, or source slide assets are embedded. The deck uses original HTML/CSS shapes and placeholder content.
How to adapt
Change CSS variables in :root, replace placeholders, add or remove slides, and print to PDF using browser print settings.
