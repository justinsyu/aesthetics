# IEGP HTML Slide Template

This folder contains a standalone 1280 x 720 HTML slide deck template for an Integrated Evidence Generation Plan.

## Files

- `index.html` - editable HTML/CSS slide deck
- `revmed_novartis_html_deck_fullpage.png` - rendered full-page QA screenshot

## Design Basis

The design is inspired by public Revolution Medicines scientific/AACR slides and Novartis investor slides. It uses original HTML/CSS only and does not copy logos, photography, charts, or proprietary slide assets.

## Usage

Open `index.html` in a browser or serve this folder locally.

Keyboard navigation:

- Right arrow / PageDown / Space: next slide
- Left arrow / PageUp: previous slide

To export, use browser print and select PDF. Print CSS sets each slide to one 1280 x 720 page.
