03

Select full workbook audit

For cost-effectiveness models, cross-sheet formulas drive outcomes. Pick the full workbook option, not only the current PSA sheet.

04

Prompt for edge cases

After the structural audit, ask for edge-case tests so the model is exercised at biologically and economically unusual inputs.

EDGE CASE TESTS
05

Choose stress categories

Select boundary values, degenerate cases, sign-flip cases, and extreme inputs. These reveal logic defects that normal PSA may miss.

06

Restore and interpret

Require baseline restoration after tests. Findings are useful only if the model returns to the original state and ICER.

Prompting pattern for HEOR teams

Scope first: "Audit the full workbook, not only the current sheet."
Trace outputs: "Map inputs, dependencies, and ICER-driving cells."
Stress deliberately: "Run boundary, degenerate, sign-flip, and extreme-input tests."
Protect baseline: "Restore all changed values and confirm the original ICER."

How to read AI findings

Materiality Prioritize defects that affect every long-horizon analysis or the base-case ICER.
Mechanism Ask which formulas, lookup tables, or state costs produced the observed behavior.
Replicate Re-run the stress case manually or with a test log before changing the model.
Document Capture screenshots, original values, changed values, outputs, and restoration status.
